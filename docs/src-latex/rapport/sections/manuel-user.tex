\chapter{Manuel utilisateur}

\section{App mobile}
\subsection{But de l'application}
Cette application mobile s'adresse aux livreurs : elle permet de s'inscrire, de se connecter, de recevoir et d'accepter des missions, de suivre un trajet, de gérer son portefeuille et son profil.

\subsection{Installation et première ouverture}
Procédure rapide depuis la racine du projet (développeur/testeur) :
\begin{enumerate}
	\item Installer \texttt{pnpm} si nécessaire :
	\begin{itemize}
		\item Option simple : \texttt{npm install -g pnpm}
		\item Ou activer Corepack et préparer pnpm : \texttt{corepack enable \&\& corepack prepare pnpm@latest --activate}
	\end{itemize}
	\item Installer toutes les dépendances (depuis la racine du dépôt) : \texttt{pnpm install}.
	
	\item Lancer en mode Tunnel pour tester sur un vrai téléphone via l'App Expo Go :
	\begin{itemize}
		\item \texttt{pnpm run mobile:tunnel}  \quad (ou \texttt{corepack pnpm run mobile:tunnel})
	\end{itemize}
    \item OU Lancer l'application mobile en mode LAN (réseau local) si vous voulez utiliser un simulateur sur PC :
	\begin{itemize}
		\item \texttt{pnpm run mobile:lan}  \quad (ou \texttt{corepack pnpm run mobile:lan})
	\end{itemize}
	\item Installer Expo Go sur le téléphone OU configurer un émulateur sur le PC. Expo Go est recommandé pour les tests réels (plus simple et fiable).
\end{enumerate}

Après ces étapes, ouvrir l'application via Expo (QR code ou lien) ; l'utilisateur arrive sur l'écran de connexion.
